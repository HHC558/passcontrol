# 密码管家 · 原生安卓版（PassControl）

一款**完全离线、部署在手机本地、不依赖浏览器**的账号密码管理 APP（原生 Android，Kotlin + Jetpack Compose + Room）。

- 🔒 数据只保存在手机本地（Room 数据库），无任何网络权限，完全离线运行。
- 首次使用设置登录密码（≥6 位）+ 密保问题；每次打开需输入密码进入。
- 忘记密码时回答密保问题即可重置，数据不丢失。
- 记录结构：平台名称 / 账号 / 密码 / 邮箱（选填）/ 创建时间（自动生成）。
- 支持新增、编辑、删除；密码默认圆点掩码，👁 显示/隐藏；**账号、密码均可一键复制**。
- 📤 一键导出全部记录为 `.xlsx`，分享到微信 / QQ 好友。
- 📥 导入 `.xlsx` 文件，自动对比差异生成预览：🔵 新增 / 🟢 修改 / 🔴 删除，可确认或取消。
- 所有记录密码使用 AES-256-GCM 加密后落库，登录密码与密保答案均不保存明文（PBKDF2-SHA256，10 万次迭代）。

## 导入预览说明

导入文件表头支持：`平台名称 / 账号 / 密码 / 邮箱（选填）/ 创建时间（选填）`（表头顺序可任意，也兼容英文表头 platform/account/password/email/createdAt）。按「平台名称 + 账号」与 APP 内数据对比：

- 🔵 **蓝色 = 新增**：文件中存在、APP 中没有的记录，确认后加入 APP。
- 🟢 **绿色 = 修改**：账号/密码/邮箱有变化的记录，预览显示“旧值 → 新值”，确认后覆盖（保留原创建时间）。
- 🔴 **红色 = 删除**：APP 中存在、文件中没有的记录，确认后从 APP 删除。
- 点击“确认导入”应用预览结果（有二次确认弹窗）；点击“取消导入”放弃本次导入，数据不变。

> 导出的 xlsx 为明文，分享前请确认接收对象可信。

## 安装到手机

1. 从 GitHub Actions 的 **passwordmanager-apk** 制品页下载 `app-release.apk`。
2. 通过微信/QQ/USB 把 APK 传到手机，点击安装（首次需允许“安装未知来源应用”）。
3. 打开「密码管家」→ 设置登录密码与密保问题 → 开始使用。
4. 全程无需联网；数据仅存在于本机。

## 本地开发（可选）

需要：JDK 17（Temurin）+ Android Studio（或 Android SDK cmdline-tools，含 `platforms;android-34`、`build-tools;34.0.0`）。

```bash
./gradlew test          # 运行 JVM 单元测试（加密 / xlsx 往返 / 差异比对）
./gradlew assembleDebug # 构建 debug APK（无需签名）
./gradlew assembleRelease # 构建 release APK（需在 keystore/ 放置 release.keystore 并设置 KEYSTORE_PASSWORD / KEY_PASSWORD 环境变量）
```

## 数据迁移（旧 PWA 版 → 本版）

旧版「密码管家 PWA」可在其设置/列表页导出 `.xlsx`，再在本 APP 中「导入」即可完成迁移；重复记录会按差异预览处理。

## 安全说明

- 登录密码与密保答案均不保存明文；PBKDF2-SHA256（10 万次迭代）派生密钥。
- 记录密码用 AES-256-GCM 加密后落库；保险库密钥由“登录密码”与“密保答案”双重包裹，忘记密码答对密保即可重置。
- 本 APP 不含任何网络权限，数据不离开手机。
